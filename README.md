# Kaggle · Практика анализа данных

**Мои решения учебных заданий и практические работы на платформе Kaggle: Python, SQL, подготовка данных и визуализация.**

Этот репозиторий объединяет материалы, с которыми я работал при изучении основ анализа данных. Здесь я закрепляю навыки, необходимые для повседневных аналитических задач: извлечь нужную информацию, привести таблицы к удобному виду, исследовать данные и представить результаты на графиках.

Основу составляют упражнения **Kaggle Learn**, дополненные практикой исследования данных.

## 🔎 С чего начать знакомство

Для быстрого обзора можно посмотреть три работы:

- **[Визуализация распределений](data_vizualization_course/exercise-distributions.ipynb)** — практика графического исследования данных.
- **[Объединение данных в SQL](advanced_sql_course/exercise-joins-and-unions.ipynb)** — упражнения на работу с несколькими таблицами.
- **[Исследование данных A/B](ab-testing-practice/ab-testing-practice.ipynb)** — проверка данных, сравнение времени на сайте, просмотров страниц и количества конверсий. Работа посвящена разведочному анализу и не содержит завершённой статистической проверки эффекта.

## 💡 Какие навыки я развиваю

Работа с заданиями помогает мне последовательно осваивать основные этапы анализа:

- **Понимать данные:** изучать структуру таблиц, типы значений и пропуски.
- **Получать нужную информацию:** использовать фильтрацию, группировки и SQL-запросы.
- **Подготавливать данные:** преобразовывать значения и объединять источники.
- **Представлять результаты:** выбирать графики под задачу и делать сравнения наглядными.
