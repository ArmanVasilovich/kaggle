# Kaggle · Data Analysis Practice

**My solutions to learning exercises and practical work on Kaggle: Python, SQL, data preparation, and visualization.**

This repository brings together materials from my study of data analysis fundamentals. It records my practice with common analytical tasks: retrieving relevant information, organizing tables, exploring data, and presenting results through charts.

The collection consists mainly of **Kaggle Learn** exercises, alongside exploratory data analysis practice.

## 🧭 What’s Inside

| Area | Skills Practiced | Materials |
|---|---|---|
| **Working with Tables** | Reading data, selecting rows, grouping, sorting, and combining tables | [Pandas](pandas_course/) |
| **Data Preparation** | Handling missing values, scaling, and normalizing numerical features | [Data Cleaning](data_cleaning_course/) |
| **Visualization** | Comparing categories, exploring distributions and relationships, and choosing suitable charts | [Data Visualization](data_vizualization_course/) |
| **SQL Fundamentals** | Selecting, filtering, aggregating, sorting, and joining data, plus structuring queries | [Intro to SQL](intro_to_sql_course/) |
| **Further SQL Practice** | Combining data with JOINs and UNIONs | [Advanced SQL](advanced_sql_course/) |
| **Exploring A/B Groups** | Initial exploration of user behavior and visual comparison of two groups | [A/B Practice](ab-testing-practice/) |

## 🔎 Where to Start

For a quick overview, take a look at these three notebooks:

- **[Visualizing Distributions](data_vizualization_course/exercise-distributions.ipynb)** — practice exploring data through charts.
- **[Combining Data with SQL](advanced_sql_course/exercise-joins-and-unions.ipynb)** — exercises involving multiple tables.
- **[Exploring A/B Data](ab-testing-practice/ab-testing-practice.ipynb)** — data inspection and comparisons of time spent, page views, and conversion counts. This notebook focuses on exploratory analysis and does not include a complete statistical assessment of the treatment effect.

## 💡 Skills I Am Developing

These exercises help me build familiarity with the main stages of data analysis:

- **Understanding data:** examining table structure, data types, and missing values.
- **Retrieving information:** using filters, aggregations, and SQL queries.
- **Preparing data:** transforming values and combining sources.
- **Presenting results:** choosing charts suited to the question and making comparisons easy to understand.
